# Lists

An unordered list:

- first item
- second item with **emphasis**
  - a nested item
  - another nested item
    - three deep
- third item

An ordered list:

1. step one
2. step two
   1. sub-step a
   2. sub-step b
3. step three

A second ordered list, which must not continue the first one's numbering:

1. one again
2. two again

Tasks:

- [ ] not done yet
- [x] finished
- [ ] a task with a nested note

  A second paragraph beneath the task.

A mixed item whose content is more than a line:

- an item
  with a lazy continuation

  and a second paragraph

  ```text
  and a code block
  ```
